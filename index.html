Loan default scoring service Complete

Python, LightGBM, MLflow, FastAPI, Docker, GitHub Actions, Azure Container Apps, Evidently

A credit default model taken from training to a live, monitored API. A lender sends a loan application and gets back a calibrated probability of default and a risk band from A to E. The model is deliberately simple; the engineering around it is the point.

Default rates rise in every band. The model under-predicts slightly in B to E because the default rate rose from 13.3% in training to 14.8% in 2015, which is why the service monitors drift.

  • Out-of-time validation. Trained on 2012–2014 loans and tested on 2015: AUC 0.681 (Gini 0.362) against 0.674 for a logistic regression baseline.
  • Leakage excluded by design. Lending Club's own grade, interest rate and instalment are left out, as are geography and free text, which can proxy protected attributes.
  • One image, one model version. CI tests that the container predicts exactly like the training code, then deploys to Azure Container Apps.
  • Monitoring and retraining. A drift report compares later vintages with training data, and a challenger model must pass a gate before a human promotes it.

Not in scope: it is a portfolio project, not a production credit decision system, and includes no fairness audit.

Futures options open-interest tracker Complete

Python, Selenium, pandas, openpyxl, pytest

Barchart shows only today's open interest in futures options. This tool saves a snapshot each day, strike by strike, so you can see where traders are building positions over time. It was built to follow coffee options and works with any futures root on Barchart, such as crude oil, corn or gold.

  • Fetches the option chains for the nearest contracts by reading the JSON the page itself loads, which is more reliable than parsing the rendered table.
  • Keeps a CSV history and rebuilds an Excel report: a summary with put/call ratios and the strikes with the highest open interest, plus a date-by-strike table and chart per contract.
  • Tested on synthetic option chains, so the tests need no network or browser.
